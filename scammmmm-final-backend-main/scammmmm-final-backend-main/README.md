# 🛡️ ScamShield: Next-Gen Cyber-Threat & Recruitment Fraud Detection Engine

**ScamShield** is a comprehensive, production-grade cybersecurity intelligence layer and machine learning fuser designed to detect and intercept fraudulent job offers, recruitment scams, and malicious URLs in real-time. 

By analyzing metadata, cross-referencing registries, applying heuristics, and fusing scores with Machine Learning models, ScamShield identifies deceitful behaviors that traditional systems miss across multiple dimensions (Domains, Network, Email, Phone, OSINT, and Salary).

---

## ⚡ Architecture & Features

ScamShield acts as a unified detection backend utilizing a modular **six-layer cyber intelligence architecture** coupled with an NLP fuser.

1. **🌐 Domain & Typo-Squatting Engine**
   - High-speed `rapidfuzz` heuristics combined with homoglyph normalization.
   - Detects sub-domain tricks (e.g., `amazon-jobs.com`), visual homoglyphs (e.g., `G00gle`, `rnicrosoft`), and URL shorteners.
   - Cross-references incoming URIs with the canonical registries of major tech and Indian IT giants.
2. **📡 WHOIS & Network Infrastructure Analysis**
   - Live querying of domain age and registry data via `python-whois`.
   - Brand-new domains (under 60 days) and those masked behind anonymizers incur heavy penalties.
   - Live IP and port resolution, blocking raw IP-based URLs immediately.
3. **✉️ Email & Contact Intelligence**
   - Advanced impersonation checks via Free Email detection (e.g., `infosys.hr@gmail.com`).
   - Throwaway and disposable email blocking (e.g., `10minutemail.com`, `tempmail.com`).
   - Shannon entropy analysis to detect autogenerated/robocall email addresses (e.g., `x7k2m9@xyz.com`).
4. **💰 Advanced Salary Anomaly Detection**
   - Dynamic top-of-market ceilings mapped by company category (Big Tech, Indian IT, Startups).
   - Flags absurdly high bait salaries and illegal below-minimum-wage fraud salaries.
5. **🧠 Unified NLP Fusion Layer**
   - Integrates with Scikit-Learn based NLP text analysis (`ml.py`) to detect upfront fee requests, wire transfers, and generic "scam language" text semantics.
   - Score Hard-Caps: If fee language is identified, the system places a hard cap on the final score (Max 20/100).
6. **🚦 Self-Healing Confidence Scoring**
   - Calculates a combined Trust/Confidence score ensuring no false positives for established companies or legitimate recruitment domains like `instahyre.com` or `careers.wipro.com`.

## 🚀 Setup & Run Instructions

### Prerequisites
- Python 3.10+
- Node.js & npm (for Frontend)

### 1. Initialize Backend

Navigate to the backend directory and set up the Python virtual environment:

```bash
cd scammmmm-final-backend-main\scammmmm-final-backend-main
python -m venv venv
venv\Scripts\activate  # On Windows
# source venv/bin/activate # On Mac/Linux

pip install -r requirements.txt
```

> **Note:** For NLP analysis, make sure the model is trained:
> `python train_classifier.py`

Start the FastAPI Backend:

```bash
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```
> The API will be available at: `http://127.0.0.1:8000/api/check`

### 2. Initialize Frontend

Open a new terminal window and navigate to the frontend directory:

```bash
cd fries-rishi-main\scamshield-frontend
npm install
```

Start the React Vite Frontend:

```bash
npm run dev
```
> The application will automatically open in your default browser at `http://localhost:5173`.

## 📝 API Integration

### `POST /api/check`

The unified endpoint accepts the following payload. All fields are technically optional, and the system dynamically builds its score based on what is available:

```json
{
  "job_url": "https://www.rnicrosoft.com/careers",
  "company_claimed": "Microsoft",
  "recruiter_email": "microsoft.recruitment@gmail.com",
  "phone_number": "+91 9876543210",
  "salary_offered": 8500000,
  "offer_text": "To process your employment, kindly transfer a refundable security deposit."
}
```

#### Sample Response: `{"verdict": "SCAM", "score": 10, "reasons": [...]}`

| Score Range | Verdict | Description |
| ---- | ---- | ---- |
| **80 - 100** | `VERIFIED` | Safe, highly trusted domain & entity. |
| **55 - 79** | `UNVERIFIED` | Cannot verify. Requires human analysis, edge cases, partial matches. |
| **30 - 54** | `SUSPICIOUS` | Significant red flags, highly likely to be dangerous. |
| **0 - 29** | `SCAM` | Critical danger flags triggered. Guaranteed Scam. |
